# Bajo El Búnker - Página Web 🎸

Proyecto de desarrollo de la página web de la banda **Bajo El Búnker**. Diseñada con una estética oscura y agresiva, optimizado para ofrecer una experiencia interactiva a los fans, incluyendo integración de música, galerías de fotos y secciones de eventos.

## 🚀 Características principales

* **Diseño Responsivo:** Adaptabilidad total para dispositivos móviles, tablets y desktop utilizando la grilla de **Bootstrap 5**.
* **Galería Interactiva:** Implementación de un *Lightbox* mediante un Modal dinámico que permite visualizar imágenes en alta resolución sin salir de la página.
* **Integración con Spotify:** Reproductor embebido para streaming directo de la discografía de la banda.
* **Gestión de Eventos:** Sección de "Tour" con lista de fechas dinámica y sección "Drunker" con carrusel de flyers históricos.
* **Estética Unificada:** Interfaz de usuario (UI) personalizada con esquemas de colores gris oscuro y acentos en rojo para reflejar la identidad visual de la banda.

## 🛠️ Tecnologías utilizadas

* **HTML5 & CSS3:** Estructura semántica y diseño personalizado (Flexbox, animaciones de hover, scrollbars personalizadas).
* **Bootstrap 5:** Framework de CSS para acelerar el desarrollo de componentes responsivos.
* **JavaScript (Vanilla):** Lógica para la manipulación del DOM, gestión del Modal de fotos y control del carrusel.
* **Git & GitHub:** Control de versiones y despliegue continuo.

## 📁 Estructura del Proyecto

* `/index.html`: Página principal (Bio y Spotify).
* `/pages/`: Contiene `media.html`, `tour.html` y `drunker.html`.
* `/assets/`: Carpeta de recursos (Imágenes de eventos, flyers y logos).
* `/css/`: Hoja de estilos principal con variables de diseño personalizadas.
